# Glossary — Ocean Fishing, in Plain Words

*Every hobby builds a little secret language. Here is the friendly translation. Alphabetical,
hand-maintained, no math.*

Last hand-checked: **2026-10-31**

## A–D

**Boat, The (The Endeavor)**
The vessel you sail in the Ocean Fishing duty. Shared with everyone aboard; there is no private
yacht option, which is exactly right.

**Boil**
A spot where fish churn the surface. Big point value if you hook into it, fine storytelling
value if you don't.

**Bronze / Silver / Gold (score tiers)**
Informal names for how a voyage's point total feels. Roughly: finished comfortably / did well /
did suspiciously well.

**Bite strength**
How hard the fish pulls before you hook. Tiny nibbles mean small fish; long drags mean
celebrities. Matches bait personality — see `04-bait-rotation-cards.md`.

**Cast**
Throwing your line. Recasting after a long wait is maintenance, not failure.

**Double Hook**
An action that hooks two fish at once when bites line up. A point multiplier for people who like
small arithmetic wins.

**Duty Finder**
The in-game queue screen. Ocean Fishing lives there — you don't sail anywhere by foot.

## E–M

**Fisher (the job)**
The class that sails. Any level that has unlocked Ocean Fishing can board; the voyage is a
friendly source of fisher experience too.

**Fish-finder**
The little radar window listing what's available in the current stretch. Re-read it whenever the
sky changes; it is the kindest screen on the boat.

**Hand-maintained**
The project's vow: tables are written and updated by people, stamped with a verify date, and
never scraped, sniffed, or auto-updated. See `README.md` for the whole ethos.

**Heavy bait**
Shorthand some decks use for the strongest bait in your tray. Match it to long, slow pulls.

**Spectral waters**
Mid-voyage windows where rarer fish appear and the water glitters. A gift, not a schedule.

**Stretch (voyage segment)**
One leg of the voyage's three-ish parts, each with its own sky and fish list.

**Voyage window**
The fixed departure slot for Ocean Fishing (see `01-voyage-windows.md`). Knowing it means
showing up on time with zero spreadsheets.

## N–Z

**Patience (the action)**
A fishing stance that changes bite timing. Entirely optional; many happy fishers never use it and
many unkillable spreadsheets assume you do.

**Profit-or-patience**
Not a real term. If someone says it on the boat, they invented it, and you're allowed to
invent terms too. This glossary includes it so glossary has at least one joke.

**Recast**
Ending a long dead pull and casting again. The unglamorous skill that separates a pleasant
voyage from a frustrating one.

**Route**
The sequence of stretches the boat sails; different route nights show different specialties.
Community resources track these in detail; this manual tracks them in memory, by hand.

**Scoreboard**
End-of-voyage tallies. Resets every trip. Take compliments seriously, scores lightly.

**Surface Slap**
An action aimed at visible surface events. Swings wildly. So fun when it lands.

**Verify date**
The stamp on every table in this project — the day a human last checked the table against the
live game. If you update a table, you move the stamp. That's the whole system, and it works.

**Verify tip**
A note under a table explaining how to check that table yourself, by hand, in game. No tools
required beyond paying attention during a voyage.
