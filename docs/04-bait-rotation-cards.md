# 4. Bait Rotation Cheat Cards — Print-or-Memorize

*Ocean fishing hands you a small tray of baits and expects you to swap them as the boat moves.
That's the whole game of "bait rotation", and it fits on a few index cards. No spreadsheets
required.*

**Hand-maintained, not automated.** Bait names and behaviors were written down by hand while
staring at a fishing log. Last hand-checked: **2026-10-31**

## Card 1 — The default rotation (memorize this one)

| Situation | Do this | Why, plainly |
| --- | --- | --- |
| Any stretch, no special window | Cast with your mid-size bait, note bite strength | A baseline causes everything else |
| Tiny, fast tugs | Swap to small-bait friendly choice; hook quickly | Small tugs on heavy bait waste time |
| Big, slow, heavy pulls | Stay patient, let it take, hook steady | Heavyweights punish impatience |
| Spectral waters open | Best bait you own, cast and re-cast fast | Every cast counts in the window |
| Weather change mid-stretch | Re-check fish-finder, then re-choose bait | Finder reflects new availability |

## Card 2 — Bait vs. bite strength

The deck gives you a small set of baits with different personalities. Double-check your own tray
on board (the game tells you what's in it); treat this card as the mental model, not a legal
document.

| Bite feel | Likely fish size | Bait family to favor |
| --- | --- | --- |
| Nibbling, rapid | small schooling fish | the light/generic bait |
| Deliberate, medium | mid-size namesake catches | the middle bait, three-patience hooks |
| Long drag, heavy | the boat's celebrities | the strong bait and a settled mood |

*(The exact bait strings vary as patches land — keep the shape of the table, refresh the words,
and stamp a new verify date.)*

## Card 3 — Actions you'll earn while you learn

| Action | When to use | Kind note |
| --- | --- | --- |
| Basic Hook | always fine | the quiet workhorse; nothing wrong with defaulting |
| Double Hook | two identical small/medium bites in a row | point bonus; great in Spectral windows |
| Surface Slap | bright splash events / boils | swings wild; fun when it lands |
| Patience (stances) | when you know the bite timing | optional; many happy fishers never bother |
| Give Up / recast | very long dead pulls | recasting is not failing; it's bait arithmetic |

## Card 4 — A first-voyage script

If you're nervous, read this before boarding and follow it literally:

1. Board via Duty Finder as Fisher.
2. Find a railing spot. Cast with the default-selected bait.
3. Hook everything, immediately, for the first stretch. Just learn the rhythm.
4. When the crew announces something specific ("big shadow port side!"), swap to the heavy bait
   and try for it.
5. If you get confused at any point: stop, re-read the fish-finder, recast. There is no timer
   punishing confusion.
6. Applaud the boat's whale if one surfaces. (Non-load-bearing step. Do it anyway.)

That's it. That's the whole rotation problem. The spreadsheets exist for people chasing record
scores; this manual exists for people chasing a nice evening.
